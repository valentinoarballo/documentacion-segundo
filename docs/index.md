# Desarrollo Frontend

## Presentación

Esta materia forma desarrolladores frontend capaces de construir una aplicación web completa, desde la lógica en JavaScript hasta una interfaz React publicada en internet y conectada a una API. El aprendizaje es progresivo y práctico: cada tema agrega una pieza a un mismo proyecto, de modo que lo aprendido nunca queda aislado.

## Objetivos

Al finalizar la cursada, el estudiante podrá:

- Escribir JavaScript moderno: variables, funciones, colecciones y asincronía.
- Manipular el DOM y manejar eventos sin librerías.
- Consumir APIs con `fetch` y `axios`, y persistir datos en el navegador.
- Construir aplicaciones React con componentes, estado, efectos, rutas y contexto.
- Implementar formularios controlados con validación.
- Trabajar en equipo con Git (Gitflow) y organizar tareas con tableros Kanban.
- Desplegar una aplicación en Vercel conectada a una API en producción.

## Proyecto transversal: una tienda online

Todos los ejemplos pertenecen a una misma aplicación de ecommerce. Cada bloque de la materia la lleva un paso más lejos:

| Bloque | Temas | Qué se construye |
|--------|-------|------------------|
| JavaScript | [1](tema1.md) a [4](tema4.md) | Catálogo de productos, totales, descuentos y reglas de stock |
| Navegador | [5](tema5.md) y [6](tema6.md) | Catálogo renderizado, carrito interactivo y persistente, datos desde una API |
| React | [7](tema7.md) a [13](tema13.md) | Componentes, estado, rutas, carrito global y formularios |
| Entrega | [14](tema14.md) a [16](tema16.md) | Flujo de trabajo en equipo, carga de productos y despliegue en producción |

## Requisitos previos

- Conocimientos básicos de HTML y CSS.
- Manejo básico de la terminal.
- Lógica de programación elemental (variables, condiciones, repeticiones).

## Herramientas

- Node.js 20 o superior y npm
- Git y una cuenta de GitHub
- Visual Studio Code
- Navegador con herramientas de desarrollo (DevTools)

## Cómo está organizada la documentación

Cada tema es una página independiente con la misma estructura:

1. **Fundamentación:** un párrafo que indica qué se verá y cómo se relaciona con el tema anterior y el siguiente.
2. **Desarrollo:** secciones breves y ordenadas, cada una con su explicación y un ejemplo aplicado a la tienda.

Los ejemplos están pensados para ejecutarse y modificarse. Se recomienda escribirlos en lugar de copiarlos y probar variaciones propias.

## Evaluación

- **Evaluación integradora** de los contenidos de JavaScript y DOM.
- **Recuperatorio** del examen integrador.
- **Examen final integrador:** la tienda completa, publicada y funcionando contra una API.
